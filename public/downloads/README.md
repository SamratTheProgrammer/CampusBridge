# CampusBridge Mobile App Downloads & Distribution

This directory hosts mobile application packages and update metadata for CampusBridge.

## Distribution Files
- `CampusBridge.apk`: Android Application Package for direct sideloading and manual installation.
- `version.json`: Release manifest, version number, build number, and changelog for in-app update checks.

## Installing on Android
1. Download `CampusBridge.apk` directly from the website.
2. Open the downloaded file on your Android device.
3. If prompted, enable "Install unknown apps" in your Android security settings.
4. Tap **Install** and launch CampusBridge.

## Installing on iOS
- Available via Apple TestFlight beta program or enterprise provisioning profile.
- You can also add CampusBridge to your iPhone Home Screen via Safari:
  1. Open CampusBridge in Safari.
  2. Tap the **Share** button.
  3. Select **Add to Home Screen**.
